Task 4 – Keylogger Tool
📌 Objective

The goal of this task is to create a basic keylogger program that records and logs keystrokes. The focus is on logging the keys pressed and saving them to a file.

🛠️ Tools & Technologies Used

Python 3

pynput library (for capturing keystrokes)

📂 Features

Records every key pressed on the keyboard.

Saves the keystrokes into a text file (key_log.txt).

Runs in the background while logging.

Helps understand how monitoring tools work in cybersecurity.

📜 Installation & Usage
1️⃣ Install required library
pip install pynput

2️⃣ Run the script
python keylogger.py

3️⃣ Check log file

All the pressed keys will be saved in a file named key_log.txt.
